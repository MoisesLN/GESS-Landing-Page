# GESS - Landing Page

Landing page do Grêmio Estudantil Seridó Sertão (GESS), desenvolvida com Next.js.

## Tecnologias

- Next.js 16.4.6
- React 19.3.0
- React DOM 19.3.0
- Tailwind CSS 4.3.3
- TypeScript 5
- ESLint 9

## Pré-requisitos

- Node.js 20.9.0 ou superior
- npm

## Instalação


```bash
git clone https://github.com/MoisesLN/GESS-Landing-Page
cd GESS_landing-page
npm install # Baixando dependências
```

### Executando localmente

```bash
npm run dev
```
A aplicação estará disponível em `http://localhost:3000`.

### Executando em modo produção
```bash
npm run build
npm run start
```
